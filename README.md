Vice Sunset Cover Studio turns up to four photos and a caption into GTA-style multi-panel cover art — diagonal poster panels, a hand-drawn synthwave sun, skyline and palms, four colour grades (Sunset, Neon Nights, Vice, Mono) — and exports a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080, fully offline in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — two sample photos are loaded already, so type a caption and hit Export PNG.
